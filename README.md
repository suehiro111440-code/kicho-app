# 記帳アプリ（Windows）統合試用版

領収書・通帳・カードを読み取り、原本と候補をアプリで確認してGoogleへ共有し、台帳と弥生用CSVを作るWindows向け試用版です。

[アプリ2026.11.14.4をダウンロード](https://github.com/suehiro111440-code/kicho-app/releases/download/v2026.11.14.4/KichoApp_Setup_2026.11.14.4.exe)

[画面付き説明資料をダウンロード](https://github.com/suehiro111440-code/kicho-user-guide/releases/download/v2026.11.14/kicho-guide.pdf)

[変更内容と試し方](https://github.com/suehiro111440-code/kicho-app/releases/tag/v2026.11.14.4)

## 入れ方と前回からの更新

1. PCで新版のセットアップをダウンロードして開きます。
2. 「インストールする」→「アプリを開く」を押します。
3. 次からはスタートメニューの「記帳アプリ 統合版 2026.11.14.4」を開きます。

更新にも今回のセットアップが必要です。Python・コマンド入力・管理者権限は不要です。デスクトップのアイコンは希望した場合に作成できます。

同じPC・Windows利用者で保存した有効なGoogle接続とAPIキーを引き続き使えます。APIキーの再発行は不要です。未登録なら有効なキーを登録し、Googleの期限切れや権限変更時は再接続します。

「前回の続きから開く」で対応する旧試用版の作業を選ぶと、原本と保存状態を新版へコピーして続けられます。旧領収書単独アプリのお客様登録・科目辞書・作成済みExcel一覧の自動移行は今後の課題です。

## 使い方

最初に「はじめの準備」でお客様・会計期間・保存先・使う科目・消費税設定を確認します。免税を選ぶと税区分「対象外」・税額「0」が候補に入ります。

新版の候補確認画面を試すときは「その他」→「新しい作業」から始めます。Googleの一覧を作成済みの作業は、②で同じGoogleの一覧を開いて続けます。

1. 「① 資料を読み取る」でGoogleまたはPCの資料を選びます。「未読取をまとめて読む」で複数ページを読み取れます。
2. 「② 一覧を確認」で原本と日付・金額・科目を見比べます。「用途の科目」が空欄なら入力します。同じ科目にする行をまとめて選び、理由や注意点を確認して対象にできます。ページ確認を記録し、「Googleの一覧に保存して開く」で共有します。
3. 「③ 台帳とCSVを作る」で出力します。完了画面で件数・合計を確認し、「台帳を開く」「弥生CSVを保存」へ進みます。

②のアプリ内の確認画面で「確認した科目を、このお客様の次回候補として記録する」を選び、対象として確認すると、相手科目・補助科目を記録できます。学習記録は同じWindows利用者向けに暗号化して保存し、「学習記録」画面で利用を停止できます。次回も候補と原本を確認して確定します。

まずは[架空領収書](https://github.com/suehiro111440-code/kicho-user-guide/releases/download/v2026.10.25/sample-receipt.png)や[架空通帳](https://github.com/suehiro111440-code/kicho-user-guide/releases/download/v2026.10.25/sample-bank.pdf)で試せます。前回Googleへ入れた架空資料も使えます。新しい資料のまとまりは「その他」→「新しい作業」から始めます。

## 保存先と接続

アプリと作業データはPCのLocalAppData/AIBanso配下へ保存します。原本・確認一覧・台帳・CSVは選択したGoogle共有先にも保存します。AI読取時に選択ページの画像をAnthropic APIへ送り、従量料金がかかります。

APIキーは本人が選択した場合にWindows利用者向けに暗号化して保存します。Google接続は登録済みの試用対象アカウント向けです。

## Windowsやブラウザーの確認画面が出たら

未署名のため確認画面が出る場合があります。その画面をサポート担当へお知らせください。画面共有でファイル名・版番号・SHA-256を確認してから一緒に進めます。

## 試用の確認範囲

自動試験180件、実行ファイルの起動・出力、セットアップの設置を確認しました。新版でGoogle取得済みの架空3資料を一括AI読取し、3ページ・9取引を確認しています。別途、内部試用版2026.11.14.2でGoogle取込・AI読取した作業を新版へコピーし、Google台帳・CSVの9取引・25列・借貸各88,600円を照合しました。

配布先PCでの新版操作と新版CSVの弥生取込は、次の試用で確認します。領収書は1ページ1枚が対象です。売上請求書・決済入金明細・返金の領収書・複数税率の複数仕訳・旧科目辞書取込は今後の課題です。
