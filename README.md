# 記帳アプリ

最新の統合版は 2026.11.17.7 です。

[アプリをダウンロード](https://github.com/suehiro111440-code/kicho-app/releases/download/v2026.11.17.7/KichoApp_Setup_2026.11.17.7.exe)

[説明資料をダウンロード](https://github.com/suehiro111440-code/kicho-user-guide/releases/download/v2026.11.17.7/kicho-guide.pdf)

PCでダウンロードしてインストールしてください。更新後はアプリの版番号を確認してください。

領収書・通帳・カードを、①資料を読み取る → ②Googleの一覧を確認 → ③台帳と弥生CSVを作る、の流れで使えます。

複数ページの一括読取、長い通帳・カードの自動分割、顧客別の科目候補、免税設定の初期入力、和暦の日付補助に対応しています。

AI読取には有効なAnthropic APIキーと従量料金が必要です。Googleでの確認・保管にはご自身のGoogleアカウントを使います。
