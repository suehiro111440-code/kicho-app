# 記帳アプリ（Windows）統合試用版

領収書・通帳・カードをひとつのアプリで読み取り、Googleの一覧で確認・修正し、台帳と弥生用CSVを作るWindows向け試用版です。ソースコードは公開していません。

## ダウンロード

[統合試用版2026.10.24.5をダウンロード](https://github.com/suehiro111440-code/kicho-app/releases/download/v2026.10.24.5/KichoApp_Setup_2026.10.24.5.exe)

[試し方と確認できている範囲](https://github.com/suehiro111440-code/kicho-app/releases/tag/v2026.10.24.5)

[画面付きの説明資料（8ページ）](https://github.com/suehiro111440-code/kicho-user-guide/releases/download/v2026.10.25/kicho-guide.pdf)

## 入れ方

1. パソコンでセットアップをダウンロードして開きます。
2. 「インストールする」、続いて「アプリを開く」を押します。
3. 次からはスタートメニューの「記帳アプリ 統合版 2026.10.24.5」を開きます。

Python・コマンド入力・管理者権限は不要です。デスクトップのアイコンは希望した場合だけ作成します。

旧アプリは自動更新されません。統合版を追加し、前のアプリ・資料・設定は残します。旧お客様登録・科目辞書・作成済みExcel一覧の自動移行には対応していません。

初回は「はじめの準備」で試用用のお客様等を設定し、Google接続・APIキー・試用専用の保存先を確認します。前回のGoogleアカウントと有効なAPIキーを使えます。

## まずは架空資料で試す

前回のGoogle上の試用資料があれば、それを使えます。「① 資料を読み取る」で資料を選び、「② 一覧を確認」でGoogleの一覧と原本を見比べます。行・ページ・仕訳等を確認してから「③ 台帳とCSVを作る」へ進みます。

資料がない場合の[架空領収書](https://github.com/suehiro111440-code/kicho-user-guide/releases/download/v2026.10.25/sample-receipt.png)と[架空通帳](https://github.com/suehiro111440-code/kicho-user-guide/releases/download/v2026.10.25/sample-bank.pdf)も用意しています。PCへ保存して①から「パソコンから選ぶ」で開くか、Googleの試用フォルダへ入れて選びます。

## 保存先と接続

アプリと作業データはPCのLocalAppData/AIBanso配下へ保存します。原本・確認一覧・台帳・CSVは選択したGoogle共有先にも保存します。AI読取時には選択ページの画像をAnthropic APIへ送り、従量料金がかかります。

利用者のAPIキー・Google認証トークン・実際のお客様資料は配布物に含めません。APIキーは本人が選択した場合に限り、Windows利用者向けに暗号化して保存します。

Google接続は登録済みの試用対象アカウント向けです。現在はテスト運用中で、期限切れ時は再接続が必要です。

## Windowsやブラウザーの確認画面が出たら

未署名のため確認画面が出る場合があります。その画面のままサポート担当へお知らせください。画面共有でファイル名・版番号・SHA-256を確認してから一緒に進めます。

## 試用の範囲

架空資料の自動試験・実行ファイル・設置後の出力を確認しています。新版領収書の実AI読取と配布先PCでの一連の操作は、試用で確認する段階です。科目辞書取込、売上請求書/決済入金、複数行仕訳等は未対応です。
