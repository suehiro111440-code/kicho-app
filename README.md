# 記帳アプリ（Windows）統合試用版

領収書・通帳・カードを読み取り、原本と候補をアプリで確認してGoogleへ共有し、台帳と弥生用CSVを作るWindows向け試用版です。

## 入れ方と前回からの更新

1. PCで新版のセットアップをダウンロードして開きます。
2. 「インストールする」→「アプリを開く」を押します。
3. 次からはスタートメニューの「記帳アプリ 統合版 2026.11.15.3」を開きます。

更新には今回のセットアップが必要です。同じPC・Windows利用者で保存した有効なGoogle接続とAPIキーを引き続き使えます。Googleの接続期限切れや権限変更時は再接続します。

「前回の続きから開く」で対応する旧試用版の作業を選ぶと、原本と保存状態を新版へコピーして続けられます。Google一覧を作成済みの作業は、②で同じGoogleの一覧を開きます。

## 今回追加した通帳の日付自動変換

通帳の取引日欄の元号・西暦表記や、明示された取引対象年・期間を使って日付を自動変換します。例えば「取引年月日（令和）」があれば、`08-05-07` を `2026-05-07` と表示します。

②で自動変換の件数と根拠を確認できます。元号や年を判断できない行は「日付が不明な行を選択」からまとめて選び、原本を確認して「日付の年をまとめて確認」で補正できます。

この機能を試すときは「その他」→「新しい作業」から、架空通帳を少量で読み取ってください。新版の読み取りで日付の根拠を取得します。

## 使い方

「はじめの準備」でお客様・会計期間・保存先・最初の科目・消費税設定を確認します。免税を選ぶと税区分「対象外」・税額「0」が候補に入ります。

1. 「① 資料を読み取る」でGoogleまたはPCの資料を選びます。送信ページと従量料金の案内を確認して読み取ります。再開時は「未読取をまとめて読む」で残りを処理できます。
2. 「② 一覧を確認」で原本と日付・金額・科目を見比べます。「用途の科目」が空欄なら入力します。同じ科目の行をまとめて選び、理由や注意点を確認して対象にします。ページの確認を記録し、「Googleの一覧に保存して開く」で共有します。
3. 「③ 台帳とCSVを作る」で出力します。完了画面で件数・合計を確認し、「台帳を開く」「弥生CSVを保存」へ進みます。

②のアプリ内の確認画面で「確認した科目を、このお客様の次回候補として記録する」を選び、対象として確認すると、相手科目と補助科目を記録できます。同じWindows利用者向けに暗号化して保存し、「学習記録」から候補の利用を停止できます。

旧領収書単独アプリのお客様登録・科目辞書・Excel一覧の自動移行は今後の課題です。

## 保存先と接続

アプリと作業データはPC内の専用領域に保存します。原本・確認一覧・台帳・CSVは選択したGoogleの保存先にも保存します。AI読取時に選択ページの画像をAnthropic APIへ送り、従量料金がかかります。

APIキーは本人が選択した場合にWindows利用者向けに暗号化して保存します。Google接続は登録済みの試用対象アカウント向けです。

未署名のWindows用試用版です。Windowsやブラウザーの確認画面が出た場合は、画面共有でサポート担当とファイル名・版番号・SHA-256を確認してから進めます。

## 試用の確認範囲

自動試験244件、実際の確認画面、最終実行ファイルとセットアップの設置を確認しました。架空2画像で取得した実AI返答を最終版で再処理し、元号凡例あり4件の自動変換と、根拠なし4件の確認表示を照合しています。

最終実行ファイルでは、架空通帳4件の日付自動変換と、3種類合計9取引・25列・借貸各88,600円の台帳・CSVを確認しました。配布先PCの新版操作、新版での実Google出力と弥生取込は、次の試用で確認します。
