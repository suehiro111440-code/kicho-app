# 記帳アプリ（Windows）配布用

領収書の写真から、お客様ごとの管理台帳（Excel）を作るツールのインストーラーです。
AI伴走者（矢嶋昌人）が、導入先へお渡しするために置いています。**ソースコードはここには含めていません。**

## ダウンロード

右側の **Releases** から、最新版の `KichoApp_Setup_….exe` をダウンロードしてください。

## 入れ方

1. ダウンロードしたファイルをダブルクリック
2. 「インストールする」を押す
3. デスクトップに出た「記帳アプリ」のアイコンから開く

Pythonなどの別途インストール、コマンド入力は不要です。管理者権限も求めません。

## 警告が出たら

このインストーラーは電子署名をしていないため、Windowsやブラウザーが「発行元が不明」「一般的にダウンロードされていません」と表示することがあります。
導入は矢嶋が画面を共有しながらご一緒に行いますので、その画面のままお知らせください。ご自身で保護機能を切る必要はありません。

## 壊れていないかの確認

各Releaseに記載の SHA-256 と、ダウンロードしたファイルの値が同じであれば、途中で壊れたり差し替えられたりしていません。

## 保存先

- アプリ本体：ローカルアプリデータの `AIBanso` → `KichoApp`
- お客様データ・APIキー：その中の `program`（パソコンの外には出ません。AI読取のときだけ、書類の画像がAnthropic社のAPIへ送られます）
